Damped Harmonic Oscillator Calculator

This calculator solves for the displacement of a mass on a spring with damping (friction), given the physical properties of the system and its starting conditions, and plots displacement x (dependent variable, Y axis) against time t (independent variable, X axis).

Governing equation:   m·x'' + b·x' + k·x = 0

Underdamped solution (ζ < 1):   x(t) = e−γt [ x0 cos(ωdt) + ((v0 + γx0) / ωd) sin(ωdt) ]
where γ = b / 2m,   ω0 = √(k/m),   ωd = √(ω02 − γ2),   ζ = γ / ω0
(Critically damped and overdamped cases are also handled.)
